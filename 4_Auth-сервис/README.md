# Auth Service

Сервис аутентификации и авторизации на FastAPI с использованием JWT токенов.

## Функциональность

- Регистрация пользователей
- Авторизация с JWT токенами
- Обновление токенов
- Обновление данных пользователя
- История входов
- Выход из системы с черным списком токенов
